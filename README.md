# Finance-Tracker 財務追蹤工具

is a sleek, modern financial intelligence web application designed to visualize real-time liquidity, cash run-rate, and budget allocations. Built with a clean UI, it features interactive 6-month income vs. expense velocity charts, category spending breakdowns, net savings rate tracking, and a comprehensive transaction ledger with Excel export and multi-language support (EN/繁).

是一款介面簡潔的現代化財務管理與分析網頁應用程式。協助使用者掌握即時總資產、收支現金流趨勢（6 個月對比圖表）、各類別支出佔比及淨儲蓄率目標，並內建完整的交易紀錄帳本、Excel 匯出與中英雙語切換功能。
